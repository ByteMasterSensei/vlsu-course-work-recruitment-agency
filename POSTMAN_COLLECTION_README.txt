ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ POSTMAN КОЛЛЕКЦИИ
================================================================================

ФАЙЛ КОЛЛЕКЦИИ: RecruitmentAgency_API.postman_collection.json

================================================================================

ИМПОРТ КОЛЛЕКЦИИ В POSTMAN
================================================================================

1. Откройте Postman
2. Нажмите кнопку "Import" в левом верхнем углу
3. Выберите файл "RecruitmentAgency_API.postman_collection.json"
4. Коллекция будет импортирована со всеми запросами

================================================================================

НАСТРОЙКА ПЕРЕМЕННЫХ
================================================================================

После импорта коллекции настройте переменные окружения:

1. Откройте коллекцию "Recruitment Agency API"
2. Перейдите на вкладку "Variables"
3. Убедитесь, что переменные настроены:
   - baseUrl: http://localhost:80 (или ваш URL сервера)
   - accessToken: (будет установлен автоматически после входа)
   - refreshToken: (будет установлен автоматически после входа)

================================================================================

ИСПОЛЬЗОВАНИЕ КОЛЛЕКЦИИ
================================================================================

ШАГ 1: АУТЕНТИФИКАЦИЯ
----------------------
1. Перейдите в папку "Аутентификация"
2. Выполните запрос "Вход" с учетными данными:
   - Email: admin@agency.ru
   - Password: admin123
   
   ИЛИ
   
   - Email: manager@agency.ru
   - Password: manager123

3. После успешного входа токены автоматически сохранятся в переменные коллекции
4. Все последующие запросы будут использовать сохраненный токен

ШАГ 2: РАБОТА С API
-------------------
После аутентификации вы можете использовать любые эндпоинты:

- Вакансии: просмотр, создание, обновление, удаление
- Избранные вакансии: добавление, просмотр, удаление
- Профили соискателей: создание, просмотр, обновление
- Подбор персонала: поиск по критериям
- Права доступа: выдача и отзыв прав
- Управление пользователями (только для админов)
- Журнал действий (только для админов)

================================================================================

СТРУКТУРА КОЛЛЕКЦИИ
================================================================================

1. Аутентификация
   - Регистрация
   - Вход
   - Обновление токена

2. Вакансии
   - Получить список вакансий
   - Получить вакансию по ID
   - Создать вакансию (Manager/Admin)
   - Обновить вакансию (Manager/Admin)
   - Удалить вакансию (Manager/Admin)

3. Избранные вакансии (требует авторизации)
   - Получить избранные вакансии
   - Добавить в избранное
   - Удалить из избранного

4. Профили соискателей (требует авторизации)
   - Получить мои профили
   - Получить все профили
   - Получить профиль по ID
   - Создать профиль
   - Обновить профиль
   - Удалить профиль
   - Обновить статус профиля

5. Подбор персонала (Manager/Admin)
   - Поиск персонала

6. Права доступа (Manager/Admin)
   - Получить все права доступа
   - Выдать право доступа
   - Отозвать право доступа
   - Проверить право доступа
   - Получить соискателей для выдачи прав

7. Управление пользователями (только Admin)
   - Получить всех пользователей
   - Получить пользователя по ID
   - Обновить пользователя
   - Удалить пользователя

8. Журнал действий (только Admin)
   - Получить журнал действий
   - Получить журнал действий пользователя

================================================================================

ОСОБЕННОСТИ
================================================================================

- Автоматическое сохранение токенов: после успешного входа или регистрации 
  токены автоматически сохраняются в переменные коллекции

- Bearer авторизация: все защищенные эндпоинты используют Bearer токен из 
  переменной accessToken

- Примеры данных: все запросы содержат примеры тел запросов с заполненными 
  данными

- Фильтрация: запросы с фильтрацией содержат примеры query параметров

================================================================================

ПРИМЕЧАНИЯ
================================================================================

- Убедитесь, что сервер запущен перед выполнением запросов
- Для некоторых эндпоинтов требуются определенные роли (Admin, Manager)
- При истечении токена используйте запрос "Обновление токена"
- Все даты должны быть в формате ISO 8601 (например: 2024-12-31T23:59:59Z)
