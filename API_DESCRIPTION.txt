API ДОКУМЕНТАЦИЯ - СИСТЕМА РЕКРУТИНГОВОГО АГЕНТСТВА
================================================================================

АУТЕНТИФИКАЦИЯ И АВТОРИЗАЦИЯ
================================================================================

POST   /api/auth/register
Описание: Регистрация нового пользователя
Тело запроса: { "email": "", "password": "", "firstName": "", "lastName": "", "middleName": "", "phone": "" }
Ответ: AuthResponseDto с токенами доступа

POST   /api/auth/login
Описание: Вход по email и паролю
Тело запроса: { "email": "", "password": "" }
Ответ: AuthResponseDto с токенами доступа

POST   /api/auth/refresh
Описание: Обновление токена доступа
Тело запроса: { "refreshToken": "" }
Ответ: AuthResponseDto с новыми токенами

Примечание: (auth) - требует аутентификации, (admin) - требует роль Admin, (manager) - требует роль Manager или Admin


ВАКАНСИИ
================================================================================

GET    /api/vacancies
Описание: Получить список вакансий с фильтрацией и пагинацией
Query параметры: search, companyName, employmentType, status, page, pageSize, sortBy, sortDescending
Ответ: VacancyListResponseDto со списком вакансий и метаданными пагинации

GET    /api/vacancies/{id}
Описание: Получить вакансию по ID
Ответ: VacancyDto

POST   /api/vacancies (manager, admin)
Описание: Создать новую вакансию
Тело запроса: CreateVacancyDto
  {
    "title": "",
    "companyName": "",
    "companyINN": "",
    "description": "",
    "requirements": "",
    "workingConditions": "",
    "salaryRange": "",
    "employmentType": 0,  // 0=FullTime, 1=PartTime, 2=Contract, 3=Internship
    "contactPerson": "",
    "contactEmail": "",
    "contactPhone": "",
    "expiresAt": ""
  }
Ответ: VacancyDto

PUT    /api/vacancies/{id} (manager, admin)
Описание: Обновить вакансию
Тело запроса: UpdateVacancyDto (все поля опциональны)
Ответ: VacancyDto

DELETE /api/vacancies/{id} (manager, admin)
Описание: Удалить вакансию
Ответ: 204 No Content

СТАТУСЫ И ТИПЫ
================================================================================

EmploymentType (тип занятости):
  0 - FullTime (Полная занятость)
  1 - PartTime (Частичная занятость)
  2 - Contract (Договор)
  3 - Internship (Стажировка)

VacancyStatus (статус вакансии):
  0 - Active (Активна)
  1 - Paused (Приостановлена)
  2 - Closed (Закрыта)

UserRole (роль пользователя):
  0 - Visitor (Посетитель)
  1 - Applicant (Соискатель)
  2 - Manager (Менеджер)
  3 - Admin (Администратор)


АВТОРИЗАЦИЯ
================================================================================

Все защищенные эндпоинты требуют JWT токен в заголовке Authorization:
  Authorization: Bearer {accessToken}

Токены выдаются при успешной регистрации или входе и содержат:
  - User ID (NameIdentifier)
  - Email
  - Role (роль пользователя)

Токены имеют ограниченный срок действия. Для обновления используется refresh token.


ОШИБКИ
================================================================================

400 Bad Request - Неверный формат запроса или данные
401 Unauthorized - Требуется аутентификация или неверные учетные данные
403 Forbidden - Недостаточно прав доступа
404 Not Found - Ресурс не найден
500 Internal Server Error - Внутренняя ошибка сервера

Формат ответа с ошибкой:
  {
    "message": "Описание ошибки"
  }
