УЧЕТНЫЕ ДАННЫЕ ПОЛЬЗОВАТЕЛЕЙ
================================================================================

В системе автоматически создаются следующие пользователи при первом запуске:

1. АДМИНИСТРАТОР
   Email:        admin@agency.ru
   Пароль:       admin123
   Роль:         Admin (Администратор)
   Имя:          Администратор
   Фамилия:      Системы
   Телефон:      +7 (999) 999-99-99
   Статус:       Активен

2. МЕНЕДЖЕР
   Email:        manager@agency.ru
   Пароль:       manager123
   Роль:         Manager (Менеджер)
   Имя:          Иван
   Фамилия:      Менеджеров
   Отчество:     Петрович
   Телефон:      +7 (999) 888-77-66
   Статус:       Активен

================================================================================

ПРИМЕЧАНИЯ:
- Эти пользователи создаются автоматически при первом запуске приложения
- Создание происходит в файле backend/Program.cs (строки 121-153)
- Если пользователи уже существуют в базе данных, они не будут созданы повторно
- Пароли хранятся в захешированном виде в базе данных (SHA256)
- Для входа используйте email и пароль через эндпоинт POST /api/auth/login

================================================================================

ДОПОЛНИТЕЛЬНЫЕ ПОЛЬЗОВАТЕЛИ:
- Другие пользователи могут быть зарегистрированы через эндпоинт POST /api/auth/register
- Все зарегистрированные пользователи по умолчанию получают роль Visitor (Посетитель)
- Администратор может изменить роль пользователя через PUT /api/users/{id}

================================================================================

РОЛИ В СИСТЕМЕ:
  0 - Visitor (Посетитель)
  1 - Applicant (Соискатель)
  2 - Manager (Менеджер)
  3 - Admin (Администратор)
