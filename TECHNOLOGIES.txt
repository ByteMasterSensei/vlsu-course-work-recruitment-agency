ТЕХНОЛОГИИ И ИНСТРУМЕНТЫ ПРОЕКТА
================================================================================

БЭКЕНД (Backend)
================================================================================

Платформа и язык:
  - .NET 9.0 (C#)
  - ASP.NET Core Web API
  - Кроссплатформенная разработка

Основные фреймворки и библиотеки:
  
  1. Microsoft.AspNetCore.Authentication.JwtBearer (v9.0.0)
     Назначение: JWT аутентификация и авторизация
     Использование: Защита API эндпоинтов, генерация и валидация токенов доступа
  
  2. Microsoft.EntityFrameworkCore (v9.0.0)
     Назначение: ORM для работы с базой данных
     Использование: Маппинг моделей на таблицы БД, миграции, LINQ запросы
  
  3. Pomelo.EntityFrameworkCore.MySql (v9.0.0)
     Назначение: Провайдер Entity Framework для MySQL
     Использование: Подключение к MySQL базе данных, выполнение SQL запросов
  
  4. AutoMapper.Extensions.Microsoft.DependencyInjection (v12.0.1)
     Назначение: Автоматическое маппинг объектов
     Использование: Преобразование между моделями и DTO, упрощение кода
  
  5. Swashbuckle.AspNetCore (v6.9.0)
     Назначение: Swagger/OpenAPI документация
     Использование: Автоматическая генерация API документации, тестирование через Swagger UI
  
  6. Microsoft.AspNetCore.OpenApi (v9.0.0)
     Назначение: Поддержка OpenAPI спецификации
     Использование: Стандартизация API документации

Архитектура:
  - MVC паттерн (Controllers, Services, Models)
  - Dependency Injection (встроенный DI контейнер ASP.NET Core)
  - Repository pattern через Entity Framework
  - DTO (Data Transfer Objects) для передачи данных
  - Service Layer для бизнес-логики

Особенности реализации:
  - JWT токены с refresh token механизмом
  - Ролевая авторизация (Visitor, Applicant, Manager, Admin)
  - CORS настройки для фронтенда
  - Логирование действий пользователей (ActionLog)
  - Система прав доступа (AccessRight)
  - Хеширование паролей через PasswordHasher
  - Автоматическое создание начальных пользователей (admin, manager)
  - Retry логика для подключения к БД
  - Чувствительное логирование для отладки

База данных:
  - MySQL 8.0+
  - Entity Framework Core Code First подход
  - Миграции через EF Core Tools


ФРОНТЕНД (Frontend)
================================================================================

Платформа и язык:
  - Node.js
  - TypeScript
  - React 18.3.1
  - Vite 7.2.4 (сборщик и dev-сервер)

Основные библиотеки и фреймворки:

  1. React (^18.3.1) и React DOM (^18.3.1)
     Назначение: UI библиотека для создания интерфейсов
     Использование: Компонентная архитектура, управление состоянием компонентов
  
  2. React Router DOM (^7.11.0)
     Назначение: Маршрутизация в одностраничном приложении
     Использование: Навигация между страницами, защищенные маршруты
  
  3. Material-UI (MUI) (^7.3.6)
     Назначение: Компонентная библиотека для React
     Использование: Готовые UI компоненты (кнопки, формы, таблицы, навигация)
     Подмодули:
       - @mui/material - основные компоненты
       - @mui/icons-material - иконки
       - @emotion/react и @emotion/styled - стилизация компонентов
  
  4. Axios (^1.13.2)
     Назначение: HTTP клиент для запросов к API
     Использование: Взаимодействие с бэкенд API, обработка запросов/ответов
  
  5. TanStack React Query (^5.90.12)
     Назначение: Управление состоянием серверных данных
     Использование: Кеширование, синхронизация данных, оптимистичные обновления

Инструменты разработки:

  1. Vite (^7.2.4)
     Назначение: Быстрый сборщик и dev-сервер
     Использование: Hot Module Replacement (HMR), быстрая сборка проекта
  
  2. TypeScript (~5.9.3)
     Назначение: Типизированный JavaScript
     Использование: Типобезопасность, улучшенная поддержка IDE
  
  3. @vitejs/plugin-react (^4.3.4)
     Назначение: Плагин Vite для React
     Использование: Поддержка JSX, оптимизация React компонентов

Архитектура фронтенда:
  - Компонентная архитектура React
  - Разделение на страницы (pages) и компоненты (components)
  - Сервисный слой для API запросов (services)
  - Утилиты для конфигурации (utils)
  - Темы для стилизации (themes)
  - Защищенные маршруты (ProtectedRoute)
  - Централизованная конфигурация Axios (axiosConfig)

Особенности реализации:
  - JWT токены хранятся и передаются через заголовки
  - Автоматическое обновление токенов
  - Обработка ошибок API
  - Адаптивный дизайн через Material-UI
  - Навигация с breadcrumbs
  - Формы с валидацией


ИНФРАСТРУКТУРА И РАЗВЕРТЫВАНИЕ
================================================================================

Контейнеризация:
  - Docker
  - Docker Compose для оркестрации
  - Отдельные Dockerfile для backend и frontend
  - Nginx для раздачи статики фронтенда

База данных:
  - MySQL в Docker контейнере
  - Инициализация через init.sql скрипт
  - Переменные окружения для конфигурации подключения

Особенности развертывания:
  - Разделение на development и production окружения
  - Переменные окружения для конфигурации
  - Автоматическое создание БД при первом запуске
  - Swagger UI доступен на /swagger


ОСОБЕННОСТИ ПРОЕКТА
================================================================================

Безопасность:
  - Хеширование паролей (не хранятся в открытом виде)
  - JWT токены с ограниченным временем жизни
  - Refresh token механизм
  - Ролевая авторизация на уровне контроллеров и методов
  - CORS настройки для защиты от межсайтовых запросов
  - Валидация входных данных через Data Annotations

Производительность:
  - Entity Framework с оптимизацией запросов
  - Пагинация для больших списков
  - Кеширование через React Query на фронтенде
  - Retry логика для устойчивости подключения к БД

Масштабируемость:
  - Модульная архитектура с разделением ответственности
  - Dependency Injection для легкого тестирования и расширения
  - DTO для изоляции слоев
  - Service Layer для переиспользования бизнес-логики

Логирование и мониторинг:
  - Журнал действий пользователей (ActionLog)
  - Логирование подключений к БД
  - Swagger для документации и тестирования API
